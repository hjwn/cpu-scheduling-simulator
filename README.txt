운영체제 CPU 스케줄링 시뮬레이터


1. 실행 방법
- CPU_Scheduler.exe 파일을 실행하면 프로그램이 시작됩니다.
- 또는 Python이 설치된 환경에서 main.py가 있는 폴더로 이동한 뒤
  python main.py
  명령어로 실행할 수 있습니다.

2. 구현 알고리즘
- FCFS
- SJF
- SRT
- Round Robin
- Priority Round Robin

3. 주요 기능
- 프로세스 이름, 도착 시간, 실행 시간, 우선순위 입력
- 알고리즘 선택 및 시간 할당량 설정
- 최종 간트 차트 출력
- 애니메이션을 통한 실행 과정 확인
- 현재 시간, 실행 중 프로세스, 준비 큐, 남은 실행 시간 표시
- 이벤트 로그 출력
- 평균 대기 시간, 평균 반환 시간, 처리율 계산

4. 결과 계산식
- 반환 시간 = 완료 시간 - 도착 시간
- 대기 시간 = 반환 시간 - 실행 시간
- 평균 대기 시간 = 전체 대기 시간 / 프로세스 수
- 평균 반환 시간 = 전체 반환 시간 / 프로세스 수
- 처리율 = 완료된 프로세스 수 / 전체 종료 시간
